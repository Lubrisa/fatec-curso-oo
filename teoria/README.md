# 📖 Módulo de Teoria

Este diretório contém todo o embasamento teórico do curso de Orientação a
Objetos. A proposta pedagógica é dividir o conteúdo em uma **trilha principal e
conceitual** e um conjunto de **apêndices de suporte**.

## 🎯 Conteúdo Principal (`01` em diante)

Os arquivos numerados a partir de `01-` constituem o **"corpo do livro"** do
curso.

- **Abordagem Agnóstica:** Os conceitos de Orientação a Objetos são apresentados
  de forma puramente teórica e conceitual, sem se prender a uma linguagem de
  programação específica.
- **Sequência Lógica:** Os capítulos seguem uma progressão incremental de
  conhecimento — desde o entendimento de paradigmas e o conceito fundamental de
  objeto, passando pela mecânica interna de funcionamento, até chegar aos
  pilares fundamentais (Encapsulamento, Abstração, Herança e Polimorfismo).

| Capítulo                          | Tópico                                                 |
| :-------------------------------- | :----------------------------------------------------- |
| `01-paradigmas-de-programacao.md` | Introdução aos paradigmas de programação e comparação. |
| `02-o-que-e-um-objeto.md`         | Definição de objeto, estado e comportamento.           |
| `03-mecanica-dos-objetos.md`      | Mecânica interna, mensagens e despacho.                |
| `04-classes.md`                   | O conceito de classe como molde/tipo                   |
| `05-encapsulamento.md`            | Ocultamento de informação e contratos                  |
| `06-abstracao.md`                 | Simplificação do domínio e interfaces                  |
| `07-heranca.md`                   | Reuso, hierarquias e especialização                    |
| `08-polimorfismo.md`              | Sobrescrita, despacho dinâmico e flexibilidade         |

## 📚 Apêndices (`apendices/`)

O diretório [`apendices/`](./apendices/) atua como **material de apoio ao
aprendizado**:

1. **Apoio aos Exercícios:** Fornece guias sintáticos e referências práticas
   necessários para a implementação dos conceitos em linguagens de programação
   (como Java) durante os exercícios.
2. **Aprofundamento Teórico:** Contém materiais complementares e conteúdos
   adicionais para quem deseja expandir a visão além do conteúdo base da
   disciplina.

👉 Para explorar os guias e referências disponíveis, acesse o [README dos
Apêndices](./apendices/).
