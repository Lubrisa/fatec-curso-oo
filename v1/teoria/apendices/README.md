# 📚 Apêndices e Guias de Referência

Este diretório reúne materiais de suporte ao conteúdo principal do curso. Os
apêndices servem tanto para **fundamentar a resolução dos exercícios práticos**
quanto para **oferecer aprofundamentos teóricos e tecnológicos** adicionais.

## 📂 Apêndices Disponíveis

### ☕ [`referencia-java/`](./referencia-java/)

Guia prático e sintático focado na linguagem **Java** (utilizando recursos
modernos do ecossistema). Como o conteúdo principal em `teoria/` aborda a
Orientação a Objetos de maneira conceitual e agnóstica, este apêndice ensina
como traduzir esses conceitos para a sintaxe e as APIs do Java.

**Tópicos cobertos:**

- **Quickstart & Setup:** Configuração do ambiente e execução.
- **Sintaxe Essencial:** Tipos de dados, variáveis, expressões e controle de
  fluxo.
- **OO na Prática:** Criação de classes, instanciação de objetos e aplicação dos
  pilares (Encapsulamento, Herança, Polimorfismo) na sintaxe Java.
- **Ecossistema:** Visão geral sobre exceções, escopo e bibliotecas fundamentais
  do Java.

## 🔮 Próximos Apêndices (Em Planejamento)

Para expandir os estudos e conectar a teoria a boas práticas avançadas de
mercado, os seguintes apêndices serão adicionados em breve:

- 🧘 **Object Calisthenics:** Conjunto de regras e boas práticas de refatoração
  para exercitar e fortalecer o design OO.
- 🧩 **Princípios SOLID:** Os 5 princípios fundamentais de design de classes
  para criar software sustentável e flexível.
- 📐 **Design Patterns (Padrões de Projeto):** Catálogo das soluções
  consolidadas para os problemas recorrentes de modelagem.
- 🛠️ **Ferramentas e Princípios de Design Isolados:** Um guia focado em
  recursos práticos e tópicos específicos de arquitetura de código.
